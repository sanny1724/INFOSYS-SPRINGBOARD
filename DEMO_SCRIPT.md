# EcoEye AI - Project Demonstration Script (6 Minutes)

## **1. Introduction (0:00 - 1:00)**
**"Good morning/afternoon everyone. Today I am presenting EcoEye AI, an intelligent surveillance system designed to protect wildlife from poaching."**

*   **The Problem:** Poaching is a crisis. Rangers cannot be everywhere at once. 
*   **The Solution:** EcoEye AI uses Computer Vision to automatically detect threats (Poachers & Weapons) in real-time and alert authorities immediately.

---

## **2. Technology Stack (1:00 - 1:30)**
**"For the technical implementation, we used a modern, high-performance stack:"**

*   **Frontend:** React.js (for a responsive, interactive Dashboard).
*   **Backend:** Python FastAPI (for high-speed API processing).
*   **AI Model:** YOLOv8 (Custom trained on our dataset to recognize Poachers, Rangers, and Weapons).
*   **Database:** MongoDB (to store user profiles and detection logs).
*   **Alerts:** Email (SMTP) & Real-time Web Notifications.
